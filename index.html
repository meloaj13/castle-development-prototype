The current HTML uses fictional data and browser state to demonstrate workflows. Production requires an approved application/backend, database, authentication, authorization, tenant isolation, encryption, audit logging, backups, secrets management and environment controls.

🔌 Integration Discovery

Virginia IEP
What supported data access is available? What can Castle read? Is any supported write-back available? What vendor/interface approvals are required?
Infinite Campus
What supported interfaces are available for student/demographic, attendance and authorized health-service data? Which system remains authoritative for each field?
Identity
What SSO/identity provider should Castle use? How are staff roles, schools and account lifecycle managed?
Notifications / Exports
Which approved services may send notifications or create secure exports, and where may those files go?

🏗️ Infrastructure Decisions

Hosting & database
Approved cloud/on-prem pattern, database technology, network boundaries and data residency requirements.
DEV → TEST → PROD
Required environments, deployment/change process and who owns each stage.
Security controls
Encryption, secrets, logging, vulnerability review, backups/recovery, incident response and security testing expectations.
Authorization model
Role + legitimate student/provider relationship + division/school scope + record sensitivity + requested action + current context.
